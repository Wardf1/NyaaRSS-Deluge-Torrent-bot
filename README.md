## Quick Overview

RSS Deluge Bot automatically:

* Reads an RSS torrent feed
* Filters releases using configurable Regex rules
* Prevents duplicate downloads using SQLite
* Sends matching torrents directly to Deluge WebUI
* Supports per-series download folders
* Supports Nyaa RSS feeds

> Use only with content you are legally allowed to download.
